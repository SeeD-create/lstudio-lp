📱 LINE公式アカウントへの設定方法（5分）

  1. LINE Official Account Manager にログイン →「トークルーム管理」→「リッチメニュー」→「作成」
  2. 表示設定を入力（タイトルは管理用なので何でもOK。メニューバーのテキストは「メニュー」がおすすめ）
  3. 「コンテンツ設定」→ テンプレートで下の表と同じ分割を選ぶ → 「画像をアップロード」でダウンロードした画像を選択
  4. 各領域のアクションに「テキスト」を選び、ボタンと同じ文言を入力（自動応答と連動させる場合。リンクなら「リンク」でURLを設定）
  5. 「保存」→ 表示をオンにして完了！

※ 画像はリッチメニュー大サイズ（2500×1686px）・1MB以下のJPGで出力されるので、そのままアップロードできます。
