REASON

動き出せない理由は、
「資格だけでは、仕事にならない」から。

学ぶ場はあっても、
届ける相手がいない知識は増えたのに、最初のお客様にどう出会えばいいのかを誰も教えてくれない。
売るものはあっても、
選ばれる理由がない同じような商品が並ぶ中で、「あなたから買う理由」をつくれないまま止まってしまう。
始め方は分かっても、
続け方が分からない一度きりで終わる関係だと、次の月にはまたゼロから集客し直しになる。

必要なのは、資格ではなく
“お客様と続いていく仕組み”でした。

SOLUTION

それが、植物美容クラブという
はじめ方です。

AI肌分析と植物由来のパーソナルコスメを軸に、
小さくはじめて、続いていく関係をつくる仕事のかたち。

POINT 01

スマホ1枚から、はじめての接客を支えてくれる

スマホで撮った1枚の写真から、話を始められます。経験が浅くても「何を話せばいいか分からない」がなくなり、同じ画面を見ながら一緒に進められます。

POINT 02

“その人だけのコスメ”という体験を届ける

植物由来の原液を組み合わせて、目の前でその方専用のコスメをつくります。既製品を仕入れて売るのではないので、価格競争に巻き込まれません。

POINT 03

場所は、小さくていい

自宅の一室、レンタルスペース、出張。大きな内装工事も在庫の山も必要ありません。今できる規模から始めて、増えたら広げる形です。

POINT 04

一人で始めても、一人で悩まない

講座の中で、集め方・伝え方・続け方までを設計します。修了後も同じ仕組みで活動する仲間とつながった状態でスタートできます。
