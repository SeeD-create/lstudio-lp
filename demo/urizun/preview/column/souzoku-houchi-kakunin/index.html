親が亡くなってから相続手続きを何もしていない｜数か月・数年たってしまったときに確認すること

公開日 2026-09-11

掲載：Officeうりずん社会保険労務士・行政書士事務所　代表・資格情報

この記事の目次何もしていなくても、まだできることがあります時間がたつと、手続きは3つに分かれます2024年4月より前の相続登記は、令和9年3月31日に注意相続放棄は、過ぎていても諦める前に確認を相続税は、まず申告が必要かを確認しますまだ請求できるお金があります預金は、放っておくとどうなるか遺産分割に期限はありませんがまとめ

※この記事は2026年9月時点の情報に基づく一般的な解説です。相続の手続きに期限があるかどうか、すでに期限を過ぎているかどうかは、亡くなった日、ご自身がいつ相続の開始を知ったか、どの手続きかによって一人ひとり異なり、期限を過ぎた場合の取り扱いも手続きごとに違います。ご自身の状況にどの期限が当てはまるかは、戸籍については市区町村の窓口、不動産登記については法務局や司法書士、相続税や準確定申告については税務署や税理士、遺族年金・未支給年金については年金事務所、相続放棄の期限や相続財産について行った行為の評価については弁護士、相続人調査や相続関係の整理については行政書士にご確認ください。

3年前に父が亡くなりました。葬儀を終えて、その後の手続きは「落ち着いてから」と思っているうちに、気がつけば3年です。実家の名義は父のまま。銀行の口座も、たしか止まったままになっている——そんな状態で、何から手をつければいいのか分からなくなってしまう方は、決して珍しくありません。

時間がたつと「今さら聞けない」「もう手遅れなのではないか」という気持ちが出てきます。ただ、相続の手続きには、時間がたっても通常どおり進められるものがかなりあります。一方で、期限が決まっていて、過ぎると取り返しがつかなくなるものもあります。

このコラムでは、親が亡くなってから数か月、あるいは数年たってしまった方に向けて、いま何を確認すればよいかを整理します。特に、実家など不動産の名義がそのままになっている場合は、期限が迫っているケースがあります。

何もしていなくても、まだできることがあります

まず、いまの状況を整理しておきます。

このコラムが想定しているのは、ご自身の親や配偶者が亡くなってから、数か月から数年ほど経過している方です。相続人がどなたなのかはおおむね分かっていて、ただ手続きに手をつけていない、という状態です。

これに対して、祖父母の代の相続が終わっていない、登記簿を見たら何十年も前に亡くなった方の名義だった、という場合は、調べ方から違ってきます。そちらは何十年も前の相続を調べる手順で扱っています。

数か月から数年という時間は、相続の手続きにとって長くはあります。ただ、致命的かというと、そうとは限りません。戸籍を集めることも、財産を調べることも、遺産分割の話し合いをすることも、いまから始められます。まず、何が急いで、何が急がないのかを分けることから始めましょう。

時間がたつと、手続きは3つに分かれます

相続の手続きは、時間の経過によって次の3つに分かれます。

分類どういうものか例
期限の確認を最優先するもの法律や制度上の期限があり、遅れると選択肢が狭まったり、加算税・過料などの問題が生じたりする相続放棄、相続税の申告、準確定申告、相続登記、葬祭費など
期限や時効を確認しながら進めるもの時間がたっていても手続きできることがあるが、請求期間や時効などの確認が必要未支給年金、高額療養費など
いまからでも進められるもの数年経過していても、通常は手続きの入口から進められる戸籍収集、財産調査、遺産分割、預貯金の相続手続き

いちばん上に当てはまるものがあれば、まずそこを確認してください。すでに期限を過ぎていても、確認する意味はあります。過ぎたことが分かれば、次にすべきことが決まるからです。

いちばん下に分類した手続きも、放置してよいという意味ではありません。ただ、数年たったことだけを理由に「もうできない」と考える必要はありません。誰が相続人かが分からなければ遺産分割も名義変更もできないので、結局はここから始めることになります。

2024年4月より前の相続登記は、令和9年3月31日に注意

いま最も急ぐのは、不動産の名義変更（相続登記）です。

2024年（令和6年）4月1日から、相続で不動産を取得したことを知った日から3年以内に相続登記を申請することが義務になりました。

ここで注意が必要なのは、2024年4月1日より前に始まった相続も義務化の対象になるという点です。施行日前から不動産を相続したことを知っていた場合は、原則として令和9年（2027年）3月31日までに申請する必要があります。一方、相続で不動産を取得したことを知ったのが2024年4月1日以後であれば、その知った日から3年以内が期限になります。

⚠ 2024年4月より前の相続も対象です

「義務化は2024年4月からだから、それより前の相続は関係ない」と考えてしまいがちですが、そうではありません。施行日前から相続したことを知っていた場合、令和9年3月31日という期限が迫っています。 実家や土地の名義が親のままになっている方は、まずここを確認してください。

正当な理由なく期限までに申請しないと、過料の対象になることがあります。制度の詳しい内容や、遺産分割がまとまらない場合の対応については、相続登記の義務化で解説しています。

相続放棄は、過ぎていても諦める前に確認を

親に借金があったかもしれない、という場合に気になるのが相続放棄です。

相続放棄には、自分のために相続が始まったことを知った時から3か月という期間があります。数年たっている場合、この期間はすでに過ぎている可能性が高いといえます。

ただし、諦める前に確認しておきたいことがあります。この3か月をどこから数えるかは、亡くなったことを知った日とは限りません。 借金の存在をまったく知らず、財産も債務もないと信じていたような場合には、事情によって別の判断がされる余地があるとされています。

一方で、「3か月では判断できないので期間を延ばしてもらう」という手続き（熟慮期間の伸長）は、3か月以内に申し立てることが要件です。すでに過ぎてしまった方が使える制度ではありません。

債権者から督促が届いた、借金があることが後から分かった、という場合は、早めに弁護士へご相談ください。 相続放棄が認められるかどうかは個別の事情による判断になり、うりずんでは判断できません。相続放棄の期間の数え方については相続放棄の期限と手続きで詳しく扱っています。

なお、相続財産について行った行為の内容によっては、相続を承認したものとして扱われる場合があります。 何が該当するかは個別の事情によって異なるため、心当たりがある方は弁護士にご確認ください。

相続税は、まず申告が必要かを確認します

相続税の申告は、相続の開始があったことを知った日の翌日から10か月以内です。数年たっている場合、この期限は過ぎています。

ただ、その前に確認しておきたいことがあります。

相続税には基礎控除があり、3,000万円＋600万円×法定相続人の数までは課税されません。相続人が3人であれば4,800万円です。相続財産などから計算した課税価格の合計額が基礎控除額を超えなければ、原則として相続税の申告は必要ありません。

ここで気をつけたいのが、次の2点です。

申告が必要かどうかは、特例を使う前の金額で判断します。 自宅の土地の評価を下げる小規模宅地等の特例を使えば基礎控除以下になる、という場合でも、特例を適用する前の課税価格で判定するため、申告そのものは必要になります。

配偶者の税額軽減や小規模宅地等の特例は、申告することが要件です。 「配偶者が相続すれば税金はかからないから」と申告しないままにしていると、特例が使えないことになりかねません。

期限を過ぎてからでも申告はできますが、無申告加算税や延滞税などが生じる場合があります。財産の総額が基礎控除を超えそうな場合は、早めに税理士へご相談ください。 相続税の期限については相続税の申告期限と納付で解説しています。

なお、亡くなった方の生前の所得状況によっては、相続の開始があったことを知った日の翌日から4か月以内に準確定申告が必要になる場合があります。事業所得や不動産所得などがあった方は、申告の要否を税理士や税務署に確認してください。

まだ請求できるお金があります

時間がたっていても、請求できるものがあります。ここは、この記事でいちばん前向きな部分かもしれません。

未支給年金は、亡くなった月分までの未払いの年金などについて、亡くなった方と生計を同じくしていた一定の遺族が、自分の権利として請求できる制度です。未支給年金を受ける権利には5年の時効があります。3年前に亡くなった方でも、まだ請求できる可能性があります。

ただし、5年を過ぎたものについては受け取れないことがあります。心当たりがあれば、早めに年金事務所または社会保険労務士にご相談ください。 未支給年金の詳しい仕組みは年金受給者が亡くなったときの手続きで扱っています。

一方、健康保険の埋葬料（費）や高額療養費などには2年の時効があります。国民健康保険などの葬祭費についても期限があるため、加入していた保険の窓口で確認してください。数年たっている場合、こちらは過ぎている可能性が高いといえます。

そして、放置していると不利になるものもあります。年金の受給停止です。

年金を受けていた方が亡くなったときは、原則として死亡の手続きが必要です。

  • ただし、日本年金機構にマイナンバーが収録されている場合は、死亡届は原則不要とされています
  • 亡くなった月より後の期間に対応する年金を受け取っていた場合には、返還が必要になることがあります
  • 一方、亡くなった月の分までの年金は、未支給年金として遺族が請求できるものです

通帳を確認して、亡くなった後にも年金の入金があるようなら、早めに年金事務所へ連絡してください。

預金は、放っておくとどうなるか

金融機関が亡くなったことを把握すると、その口座は凍結されます。引き出しも振込もできない状態です。

この状態は、相続の手続きをするまで続きます。放置しても口座が消えてしまうわけではありませんが、公共料金の引き落としが止まったり、家族が立て替え続けることになったりします。

長期間まったく取引のない預金は、休眠預金として扱われることがあります。ただし、休眠預金になった後でも、手続きをすれば払い戻しを請求することができます。「もう引き出せない」ということはありません。

口座の解約や払戻しなどの相続手続きでは、戸籍や相続関係を確認する書類などが必要になります。必要書類は、遺言の有無や手続内容、金融機関によって異なります。複数の口座がある場合は早めに着手する方が楽です。詳しくは銀行口座が凍結された時の対処法をご覧ください。

遺産分割に期限はありませんが

誰が何を相続するかを決める遺産分割の話し合いには、法律上の期限がありません。数年たっていても、いまから始められます。

ただし、時間がたつことで変わることがあります。

相続開始から10年を過ぎると、原則として、特別受益や寄与分を反映した具体的相続分による遺産分割ができなくなります。特別受益は、生前に多くの援助を受けていた相続人がいた場合にその分を考慮するもの、寄与分は、親の介護や事業を支えていた相続人の貢献を考慮するものです。

ただし、10年以内に家庭裁判所へ遺産分割を求めている場合や、10年経過後でも相続人全員が合意した場合などには例外があります。

数年前に始まった相続であれば直ちに10年を迎えるわけではありませんが、長く放置する理由にはなりません。

もう一つ、相続人が亡くなることがあります。 手続きをしないうちに相続人の一人が亡くなると、その方の相続人が加わり、話し合いに参加する人が増えます。関係が遠くなるほど、まとまりにくくなります。詳しくは代襲相続・数次相続とはで扱っています。

相続人の一人と連絡が取れない場合や、判断能力の低下によって本人が遺産分割について意思表示できない場合には、通常の協議だけでは進められないことがあります。状況によっては家庭裁判所の手続きが必要になります。

なお、祖父母の代など、かなり古い相続では別の経過措置が関係することがあります。 古い相続の調べ方は上でご紹介したコラムで解説しています。

まとめ

親が亡くなってから数か月、あるいは数年たってしまっていても、できることは残っています。

まず確認していただきたいのは、期限のあるものです。不動産の名義がそのままになっている場合、2024年4月1日より前から相続を知っていたときは令和9年3月31日という期限があります。 ここが最も急ぎます。

相続税は、課税価格の合計額が基礎控除額を超えなければ原則として申告は必要ありません。ただし特例を使う場合には申告が要件になるため、財産の総額が基礎控除を超えそうなら確認が要ります。

未支給年金のように、まだ請求できるものもあります。逆に、年金の受給停止を届け出ていないと、後から返還を求められることがあります。

戸籍を集めること、財産を調べること、遺産分割の話し合いをすることは、いまからでも始められます。「もう遅い」と考えて動かないでいる時間の方が、実際には不利益を大きくします。
