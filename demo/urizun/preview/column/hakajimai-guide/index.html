墓じまいの手続きと費用｜改葬許可の流れと注意点を行政書士が解説

公開日 2026-07-27 ／ 更新日 2026-08-30

掲載：Officeうりずん社会保険労務士・行政書士事務所　代表・資格情報

この記事の目次墓じまいと改葬の違い｜遺骨の移転には改葬許可が必要墓じまい・改葬の手続きの流れ主な必要書類と追加で確認する書類墓じまいにかかる費用の目安と内訳離檀料をめぐる注意点｜一律の基準はない墓じまいで失敗しないためにうりずんに相談できることまとめ

※この記事は2026年7月時点の情報に基づく一般的な解説です。改葬の手続きや必要書類は市区町村によって異なり、費用も墓地の状況によって大きく変わります。実際の手続きは、お墓のある市区町村や墓地の管理者、または専門家にご確認ください。

「田舎のお墓を守る人がいなくなった」「遠くて墓参りに行けない」——そうした事情から、お墓を片付ける「墓じまい」を検討する方が増えています。

ただ、墓じまいは、ただお墓を撤去すればよいというものではありません。お墓に納められている遺骨を別の場所へ移すには、「改葬（かいそう）」という手続きが必要で、市区町村への申請も含まれます。手順を踏まずに遺骨を動かすことはできません。

この記事では、墓じまいの手続きの流れ、費用の目安、そして離檀料をめぐる注意点を、川崎の行政書士が整理します。手続きの入口を知って、落ち着いて準備を進めるための地図としてご活用ください。

墓じまいと改葬の違い｜遺骨の移転には改葬許可が必要

「墓じまい」は、お墓を撤去して更地に戻し、墓地を管理者に返すことを指す言葉として使われています。

一方、その過程で必ず関わるのが「改葬」です。改葬とは、お墓に納められている遺骨を、別の場所へ移すことをいいます。遺骨の移動は、墓地埋葬法という法律にもとづいて手続きが定められており、勝手に動かすことはできません。

具体的には、いま遺骨が納められている市区町村に「改葬許可」を申請し、「改葬許可証」の交付を受ける必要があります。この許可証がなければ、遺骨を取り出して別の場所へ納めることはできません。墓じまいを考えるときは、まずこの「改葬という手続きがある」ことを押さえておくのが出発点です。

墓じまい・改葬の手続きの流れ

墓じまいは、おおまかに次の順序で進みます。順番を意識しておくと、手戻りを防げます。

1. 親族と相談する

お墓は、ご家族・ご親族にとって共通の存在です。後になって「勝手に片付けた」とならないよう、まず関係する方々と方針を話し合っておきます。遺骨の移し先をどうするかも、この段階で相談しておくと安心です。

2. 現在の墓地の管理者に事前確認する

墓地や寺院の管理者に、墓じまいを考えている旨を早めに伝えます。墓地使用者が誰の名義になっているか、遺骨が何柱納められているか、返還や撤去に関する独自のルールがあるかを確認しておきます。寺院墓地の場合は、この段階で離檀（檀家をやめること）の相談も出てきます。

3. 移し先（受け入れ先）を決める

新しい供養先を決めます。永代供養墓、樹木葬、納骨堂、別のお墓への移動など、選択肢はさまざまです。受け入れ先が決まると、その管理者から受け入れを証明する書類を発行してもらえることが多くあります。

4. 書類をそろえて改葬許可を申請する

現在の墓地がある市区町村の役所に、改葬許可を申請します。申請が認められると「改葬許可証」が交付されます。必要な書類は市区町村によって異なるため、事前に確認しておきましょう（次章で解説します）。

5. 遺骨を取り出し、移し先に納める

改葬許可証を受け取ったら、遺骨を取り出します。ご希望に応じて、取り出しの前に閉眼供養（魂抜き）を行う方もいます。取り出した遺骨は、改葬許可証とともに移し先の管理者に渡し、納めます。

6. 墓石を撤去し、区画を返還する

石材店に依頼して墓石を撤去し、区画を更地に戻して管理者に返します。ここまでで、墓じまいがひととおり完了します。

主な必要書類と追加で確認する書類

改葬許可の申請に必要な書類は、市区町村によって少しずつ異なります。ここでは、多くの自治体で共通して求められる基本的なものを挙げます。

基本となる書類

  • 改葬許可申請書：市区町村の窓口で入手するか、公式サイトからダウンロードします。亡くなった方や申請者の情報を記入します。
  • 埋蔵（納骨）の事実を証明する書面：現在の墓地・納骨堂の管理者に、遺骨が納められていることを証明してもらいます。改葬許可申請書の管理者記入欄への署名・押印で足りる場合もあります。

状況に応じて求められる書類

  • 墓地の使用者と申請者が異なる場合の、使用者の承諾書や委任状
  • 移し先の受け入れを証明する書類（受入証明書、永代使用許可証の写しなど)

なお、受け入れ先の証明書類は実務上よく求められますが、必要かどうかや様式は自治体によって扱いが異なります。全国一律ではありませんので、必ず申請先の市区町村の案内を確認してください。

墓じまいにかかる費用の目安と内訳

墓じまいの費用は、お墓の状況によって大きく変わります。同じ広さでも、重機が入れる場所か手作業か、基礎の撤去が必要か、遺骨が何柱あるか、地域はどこかによって、金額は変動します。そのため、以下はあくまで目安として捉え、実際には複数の石材店から見積もりを取ることをおすすめします。

主な費用の内訳は、次のとおりです。

  • 墓石の解体・撤去費用：区画を更地に戻すための工事費です。1平方メートルあたり10万〜15万円程度が目安とされますが、立地や基礎の状況で大きく変わります。
  • 閉眼供養のお布施：希望する場合、3万〜10万円程度が一般的とされます。
  • 移し先の費用：永代供養墓、樹木葬、納骨堂など、選ぶ供養方法によって幅があります。
  • 行政手続きの費用：改葬許可証の交付手数料などで、数百円〜千円程度です。遺骨1柱ごとに1通必要な自治体もあります。

これらを合計すると、総額は数十万円から百万円を超えることもあり、条件によって幅があります。なお、自治体によっては、墓じまいや墓地の返還に対する補助金・還付金の制度がある場合もありますので、お墓のある市区町村に確認してみるとよいでしょう。

離檀料をめぐる注意点｜一律の基準はない

寺院墓地の墓じまいでは、檀家をやめる際に「離檀料」を求められることがあります。ここは、墓じまいで最もトラブルになりやすい部分ですので、正しく理解しておきましょう。

離檀料は、法律で一律に定められた支払い義務や金額の基準があるものではありません。長年お世話になった寺院への感謝の気持ちとして、お布施の一部と考えて渡す方が多いのが実情です。

ただし、注意したいのは、離檀料と、それ以外に本来支払うべきものを分けて考えることです。墓地の使用契約にもとづく費用、未払いの管理料、区画を元に戻すための費用（原状回復費用）などは、離檀料とは別に確認が必要です。「離檀料」という名目にすべてが含まれているのか、別々なのかを、管理者に確認しておきましょう。

なお、国民生活センターにも、高額な離檀料を請求されたという相談が寄せられています。同センターは、離檀料には明確な基準がないため、納得できない場合はまず寺院とよく話し合うことを案内しています。話し合いでも折り合いがつかず、法的な紛争になりそうな場合は、弁護士に相談するのが適切です。

墓じまいで失敗しないために

墓じまいをスムーズに進めるために、次の点を押さえておくと安心です。

  • 親族の合意を先に得ておく：後からの「聞いていない」を防ぎます。祭祀を承継する立場の方がいる場合は、特に丁寧に話し合いましょう。
  • 現在の墓地の管理者に、最初に相談する：名義や遺骨の数、独自のルールを早めに確認しておくと、手続きが滞りません。
  • 移し先を先に決めておく：改葬許可の申請には、移し先が決まっていることが前提になる場合があります。
  • 費用は複数の見積もりを取る：撤去工事の費用は業者や条件で差が出ます。総額を早めに把握しておきましょう。
  • 書類は申請先の市区町村で確認する：必要書類は自治体ごとに異なります。思い込みで進めず、公式の案内で確認するのが確実です。

うりずんに相談できること

うりずん相続手続き相談室では、行政書士として、改葬許可申請書などの書類の作成や、手続きの進め方の整理をお手伝いできます。墓じまいは、親族との相談、墓地管理者への確認、移し先の決定、行政への申請と、いくつもの段階が重なります。「何から手をつければよいか」という段階から、順序立てて整理するお手伝いをします。

一方で、離檀料の金額をめぐる交渉や、寺院との契約解釈をめぐる紛争の代理は、行政書士の業務の範囲外です。そうした場面では、提携する弁護士と連携し、適切な相談先へおつなぎします。石材店による撤去工事や、移し先の供養先の手配は、それぞれの事業者が担います。

なお、墓じまいの申請先は、お住まいの場所ではなく、原則として現在お墓がある市区町村です。川崎にお住まいで、お墓が地方にある場合でも、申請は墓地のある市区町村に対して行います。遠方で手続きが難しい場合の進め方も含めて、ご相談を承っています。相続や終活全体を見据えた準備については、おひとりさまの終活完全ガイドや、死後事務委任契約について解説した記事もあわせてご覧ください。

まとめ

  • 墓じまいで遺骨を移すには、「改葬」という手続きが必要です。現在遺骨がある市区町村に改葬許可を申請し、改葬許可証の交付を受けます。
  • 手続きは、親族との相談 → 現在の墓地管理者への事前確認 → 移し先の決定 → 書類をそろえて改葬許可を申請 → 遺骨の取り出し・納骨 → 墓石の撤去・返還、という流れで進みます。
  • 必要書類は市区町村によって異なります。基本は改葬許可申請書と、埋蔵の事実を証明する書面です。受け入れ先の証明書類なども求められることがあります。
  • 費用はお墓の状況で大きく変わります。撤去工事や供養方法によって総額に幅があるため、複数の見積もりを取りましょう。
  • 離檀料には一律の基準はありません。感謝の気持ちとして渡す方が多い一方、未払い管理料や原状回復費用とは分けて確認しましょう。高額請求で折り合わない場合は弁護士に相談を。
  • 申請先は、お住まいの場所ではなく、原則として現在お墓がある市区町村です。うりずんは書類作成や手続きの整理をお手伝いし、紛争は弁護士と連携します。
