01 — 3種類と、拠点の差し替え

差し替えるのは、
この1か所だけです。

上のコース切替と教室切替は、飾りではなく実際の納品構造です。文言・色・イラスト・地図は、HTMLの先頭にあるこの記述だけを見ています。ここを書き換えれば、3種類にも6種類にも増やせます。

コースを足すとき

// 1コース＝1ブロック。ここに足すだけで、タブも中身も色も増えます。 { key: 'rika', name: '理科実験', color: '#9b5de5', catch: '理科が、すきになる教室。', points: [ '毎回かならず実験をします', … ] }

教室を足すとき

// 教室名・住所・地図・電話も1か所にまとまっています。 { name: 'ひがし川校', addr: '○○市○○町3-1-2', access:'○○駅 徒歩4分', tel: '000-000-0000', map: '○○市役所' }

ご自身でHTMLを編集されるとのことでしたので、この形にしています。1ファイルの先頭だけを見ればよく、デザイン側のコードには触れずに済みます。3種類を別々のファイルでお納めすることも、この1ファイルで6種類ぶんを切り替える形でお納めすることも、どちらでも対応できます。

03 — SEO と GEO（AIO）

AIにも読める形で書きます

検索エンジン向けの見出し構造・表示速度・スマートフォン対応に加えて、生成AIが引用しやすい形の構造化データを入れます。「○○市 子ども プログラミング教室」のような質問にAIが答えるとき、教室名・料金・場所・よくある質問を、AIが誤らずに拾えるようにしておくためです。

// 実際に入れる構造化データ（抜粋） { "@type": "Course", "name": "キッズプログラミング", "provider": { "@type": "EducationalOrganization", "name": "ミライク" }, "offers": { "price": "8800", "priceCurrency": "JPY" }, "location": { "@type": "Place", "address": "○○市○○町1-2-3" } }

あわせて FAQPage と LocalBusiness も入れます。拠点を増やされたときは、上の教室ブロックを足すだけで構造化データ側も自動でついてきます。
