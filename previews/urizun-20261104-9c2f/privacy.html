個人情報の取り扱い

本サイト「うりずん運送業サポート」は、Officeうりずん社会保険労務士・行政書士事務所が運営しています。本サイトのフォームと診断でお預かりする個人情報は、個人情報取扱事業者である前西原清城が、個人情報の保護に関する法律その他の関係法令に従って取り扱います。

1. 個人情報取扱事業者

  • 個人情報取扱事業者：前西原 清城
  • 屋号：Officeうりずん社会保険労務士・行政書士事務所
  • 所在地：〒210-0806 神奈川県川崎市川崎区中島2-13-4 テルス川崎中島レジデンス1階
  • 個人情報の管理責任者：前西原 清城
  • お問い合わせ先：「12. お問い合わせ窓口（苦情・ご相談の申出先）」のとおり

2. 取得する情報

  • 60分無料相談のお申し込み：社名、担当者名、メールアドレス、第1〜第3希望の日時、相談方法、相談テーマ、相談内容、Officeうりずんを何でお知りになったか（「その他」の場合はその内容）
  • 一般のお問い合わせ：社名、氏名、役職（いずれも任意）、メールアドレス、問い合わせ内容
  • 診断：相談のお申し込みに引き継ぐ操作をされた場合、またはお申し込み後の専用診断をご利用になった場合の、診断の回答と結果
  • 自動で記録する情報：受付番号と受付日時、Cookie に保存する識別子、IP アドレスを基に生成した識別情報（「5. Cookie と IP アドレス」をご覧ください）

3. 利用目的

お預かりした個人情報は、次の目的に利用します。

  • ご相談・お問い合わせへの回答
  • ご本人へのご連絡（受付の自動返信メールを含みます）
  • 相談日程の調整
  • 受付記録と対応履歴の管理
  • ご依頼内容の確認と、ご依頼いただいたサービスの提供
  • サービスの改善
  • お問い合わせ経路の集計・分析（「Officeうりずんを何でお知りになりましたか？」の回答などを使います）
  • 不正利用や迷惑送信への対応
  • 法令上必要な記録と対応

取得した個人情報を、ご本人のご依頼やご同意なく、宣伝メールや新サービスの営業案内の送付に利用しません。ご相談・お問い合わせへの回答、ご依頼いただいた業務に関するご連絡、法令上必要なご連絡は行います。

4. 診断の利用

診断は、氏名やメールアドレスを入力せずにご利用いただけます。結果を表示するだけでは、回答を保存しません。診断の結果画面から相談のお申し込みに引き継ぐ操作をされた場合に限り、回答と結果を保存し、お申し込みと結び付けます。引き継ぐ操作のあと、お申し込みに至らなかった場合の回答と結果は、30日の保存期限が過ぎたあと、WordPress の定期処理で削除されます。アクセス解析へ具体的な回答や個人情報を送りません。

5. Cookie と IP アドレス

本サイトでは、診断結果と相談のお申し込みを結び付ける処理、フォームの送信、申込み後の専用診断その他、受付処理に必要な場合に、ランダムな識別子を Cookie へ保存します。この Cookie の有効期間は30日です。Cookie には、氏名、メールアドレス、相談内容その他のフォーム入力内容を保存しません。通常の固定ページやコラム一覧を閲覧しただけでは、この Cookie を新たに作成しません。

診断の回答と結果は、相談のお申し込みに引き継いだ場合、または申込み後の専用診断を利用した場合に、該当する申込みと関連付けて保存します。

迷惑送信や連続送信を防止するため、フォームおよび診断の送信時に、IP アドレスと WordPress の秘密鍵から生成した識別情報を使用します。この識別情報は、生成から2時間を過ぎると送信回数の判定には使用せず、その後の定期処理で削除します。テーマは、この処理のために元の IP アドレスを受付記録へ保存しません。

6. 第三者提供と委託

法令に基づく場合など法律で認められた場合を除き、ご本人の同意なく個人データを第三者へ提供しません。サービス提供に必要な範囲で個人データの取扱いを外部事業者へ委託する場合は、委託先のサービス内容や安全管理の状況を確認し、必要な監督を行います。

本サイトの運営とメールの送受信のため、エックスサーバー株式会社のレンタルサーバーサービスを利用しています。

7. 保存期間

受付記録と、受付記録に関連付けた診断の回答・結果は、受任に至らなかった場合、最終対応から原則1年間を保存期間の上限とします。当事務所は月1回、保存している受付記録を確認し、保存期間を経過した情報および利用の必要がなくなった情報を削除します。

ただし、次の場合は、必要最小限の範囲で保存期間を延長することがあります。

  • 法令上の保存義務がある場合
  • 紛争や苦情への対応に必要な場合
  • ご本人から継続相談のご希望がある場合
  • その他、保存を続ける具体的かつ合理的な必要がある場合

受任した案件の業務記録は、問い合わせ記録とは分けて管理し、関係法令に基づく保存義務や案件対応に必要な期間に従って保存します。問い合わせ記録の重複した控えは、業務記録への移管後、不要になり次第削除します。

8. 削除の方法

当事務所が管理する WordPress の受付記録とメールボックスから、通常の業務で利用できないよう削除します。フォームの受付内容を紙に出力した場合は、不要になった後、裁断その他の判読できない方法で廃棄します。サーバー事業者等が管理するバックアップやログに一時的に残る情報は、各サービスの保存・更新の仕組みに従って順次消去されます。

9. バックアップ内の情報

バックアップ内の情報は、障害復旧および安全な運用のためにのみ利用します。通常業務に利用するものではありません。バックアップに含まれる情報は、保存世代の更新やサービス提供事業者の保存期間に従って順次消去されます。バックアップを復元した場合は、既に削除対象となっている情報が通常業務で再利用されないよう確認し、必要に応じて再度削除します。

10. 安全管理のために講じた措置

当事務所は、お預かりした個人データの漏えい、滅失または毀損を防ぐため、次の措置を講じています。

組織的安全管理措置

  • 個人データの管理責任者を定めています。
  • 受付記録と通知メールを閲覧・利用できる者を、当事務所内の業務上必要な者に限定しています。
  • 保存期間を定め、月1回、保存している受付記録を確認し、保存期間を経過した情報と利用の必要がなくなった情報を削除します。

人的安全管理措置

  • 個人データを取り扱う当事務所の代表は、社会保険労務士法第21条および行政書士法第12条により、業務上知り得た秘密を守る義務を負っています。

技術的安全管理措置

  • 受付記録は、本サイトの管理画面でだけ閲覧できる非公開の記録として保存し、一般公開のページからは閲覧できません。
  • 管理画面のアカウントを限定しています。
  • 管理画面へのログインを保護するため、セキュリティ対策用のプラグインを導入しています。
  • 本サイトとの通信は、SSL/TLS により暗号化しています。
  • フォームには、短時間の連続送信を制限し、機械的な迷惑送信を受け付けない仕組みを設けています。

安全管理のために講じた措置の具体的な内容は、お問い合わせ窓口へのお問い合わせに応じて、遅滞なくお答えします。

11. 保有個人データの開示等のご請求

当事務所が保有する個人データについて、ご本人またはその代理人から、利用目的の通知、開示、内容の訂正・追加・削除、利用の停止・消去、第三者への提供の停止、第三者提供記録の開示（以下「開示等」）のご請求があった場合は、次のとおり対応します。

  • 受付窓口：当事務所の個人情報のお問い合わせ窓口（「12. お問い合わせ窓口（苦情・ご相談の申出先）」）
  • 受付方法：一般のお問い合わせフォーム、またはお電話でご連絡ください。ご請求の内容を伺い、手続の方法をご案内します。
  • ご本人の確認：お申し込み時のメールアドレスなど、当事務所が保有している情報との照合を基本とします。照合で確認できない場合に限り、本人確認書類の提示をお願いすることがあります。本人確認書類をご提出いただく場合は、ご請求に不要な番号等（マイナンバー、本籍地、各種の記号・番号など）を見えないようにしてお送りください。本人確認のためにお受け取りした書類は、確認後に適切な方法で削除・廃棄します。
  • 代理人によるご請求：法定代理人、またはご本人から委任を受けた代理人によるご請求の場合は、代理人ご本人の確認に加えて、代理権を確認できる書類（委任状など）を確認します。
  • 手数料：原則として無料です。郵送や記録媒体での交付など、特別な実費が生じる場合は、事前にご本人にご説明し、ご了承を得たうえで対応します。
  • ご請求に応じられない場合：法令上の保存義務などにより、ご請求に応じられない場合や削除できない情報がある場合は、その理由と取扱いをご説明します。
